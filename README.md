# 周易占卦 · 주역 동전점

동전 세 닢을 여섯 번 던져 괘를 세우고, 본괘·지괘·점단으로 풀이를 읽는 웹앱입니다.
먹과 한지, 옻칠과 금박, 주인(朱印)을 바탕으로 한 화면에서 3D 동전이 실제 물리로 구르고 눕습니다.

## 흐름

1. **인트로**: 한지 위로 먹이 번지고, 여섯 효가 붓으로 그어지고, `周易` 제목과 인장이 찍힙니다(약 3초).
   - **던지기 화면으로 이어지는 전환(1.2초, ease-out)**: 가운데부터 먹 자국 모양(들쭉날쭉한 가장자리, `src/assets/ink-mask.svg`)으로 한지가 걷히고,
     같은 길이·같은 곡선으로 3D 카메라가 위에서 내려다보다 손 앞 시점으로 내려앉습니다. 글씨는 살짝 커지며 옅어지고, 끝 무렵 동전이 손 안으로 떨어집니다.
     3D 장면은 붓질이 끝난 직후 미리 만들어 두어 전환이 멈칫하지 않습니다. 건너뛰기는 0.4초, 동작 줄이기 설정이면 겹쳐 사라지기(0.3초)만 합니다.
   - 같은 세션에서 다시 열면 짧은 인트로, 공유 링크로 들어오면 생략합니다. 아무 곳이나 누르거나 `건너뛰기`, 키 입력으로 넘길 수 있습니다.
2. **던지기 화면(한 장)**: 인트로 다음은 곧바로 던지기 화면입니다. 별도의 질문·안내 단계가 없습니다.
   - 위쪽 한 줄 `問 물을 것을 적어 두세요 (선택)`: 누르면 늘어나고(200자), 결과 상단과 問占 맥락으로 이어집니다. **공유 링크에는 담기지 않습니다.**
   - 아래쪽에는 안내 한 줄("질문을 마음에 깊이 품고 여섯 번 던지세요")과 큰 주 동작 하나만 둡니다.
     버튼 이름은 기기에 맞춰 `흔들어 던지기`(흔들기 감지 폰), `눌러 흔들고 놓아 던지기`(터치), `눌러서 흔들고, 놓아 던지기`(마우스)이고, 버튼 안에 `初爻 1/6` 진행이 있습니다.
   - 소리, 흔들어 던지기 켜고 끄기, 효 직접 고르기, 점괘 보는 법(`占法`)은 상단 메뉴(삼효 모양 단추)에 모았습니다. 효 직접 고르기는 아래 작은 링크로도 열 수 있습니다.
3. **던지기**: 동전 세 닢은 판 앞쪽, 보는 사람 쪽 공중의 **손(보이지 않는 그릇)** 안에 있습니다. 옅은 사발 윤곽과 탁자 위 그림자로만 손을 암시합니다.
   - **누르고 흔들다 놓기**: 던지기 버튼(또는 스페이스·엔터, 판 위를 길게 누르기)을 누르고 있는 동안 손이 사람 손처럼 불규칙하게 흔들리고
     동전이 그 안에서 부딪힙니다. 놓으면 손이 열리며 판 가운데 쪽으로 던져집니다. 오래 흔들수록 조금 더 세게 던집니다. 짧게 탭하면 잠깐 흔든 뒤 던집니다.
   - **판 위를 끌어 던지기(데스크톱)**: 판 위를 누른 채 움직이면 손이 따라 움직이고, 놓기 직전 끄는 방향·빠르기가 던지는 방향·세기가 됩니다.
   - **폰 흔들어 털기**: 모션 센서가 있는 폰에서는 가속도가 손(그릇)을 흔들고(손목 스프링 모형, 저역 필터·진폭 제한), 털면 던져집니다.
     iOS 13+ 는 첫 던지기 버튼을 누를 때 그 동작 안에서 조용히 권한을 묻고, 거부·미지원이면 버튼 방식만 씁니다. 흔들어 던진 효에는 "흔들어 던짐"이 작게 붙습니다.
   - 던질 때마다 세 동전의 앞뒤와 효(少陽·老陰 등)를 알려 주고 왼쪽 효 사다리에 한 줄씩 쌓입니다(老陽 ○, 老陰 × 표시). 잠시 뒤 동전은 손으로 돌아옵니다.
   - **다시 던지기**: 10초 안에 세 동전이 모두 판 안에서 착지·저속·평평 조건을 채우지 못하면 그 효는 기록하지 않고 동전을 거둬 다시 던지게 합니다.
   - **판 없이 던지기**: 던지기 화면에 들어오고 8초가 지나도 물리 엔진이 준비되지 않으면 [판 없이 던지기]가 나타나고, 물리 엔진을 불러오지 못하면 바로 이 방식으로 던집니다.
     이때는 `crypto.getRandomValues` 로 공정한 동전 세 닢을 정합니다. 물리 엔진이 나중에 준비되면 3D 던지기로 돌아갑니다.
   - **효 직접 고르기**: 손으로 동전을 던졌거나 이미 얻은 괘가 있으면 初爻부터 上爻까지
     老陰(6)·少陽(7)·少陰(8)·老陽(9)을 고릅니다(각 값 옆에 동전 조합 힌트). 고르는 동안 괘 그림과 본괘·지괘 이름이 바로 보이고,
     여섯 줄을 다 채우면 [점괘 보기]가 켜집니다. 던지던 중에 열면 이미 던진 효가 채워져 있고, 진행 중이던 던지기는 취소됩니다.
     결과는 던진 괘와 같은 경로(점단·問占·공유)를 타며 "직접 입력한 괘" 표시가 붙습니다.
4. **결과(한지 두루마리)**: 本卦·之卦 그림과 이름, 괘사·대상, 占斷(변효 개수에 따른 판단 근거), 問占(점괘에게 묻기, 멀티턴).
   적어 둔 물음이 있으면 첫 칩이 "품은 질문에 대한 풀이 보기" 입니다. 묻기는 물음과 품은 질문을 AI 풀이 서버로 보낸다는 고지를 함께 보여 줍니다.
   답은 토큰이 오는 대로 흘러나옵니다(NDJSON 스트리밍, 첫 글이 오기 전까지는 "괘를 읽는 중" 표시). 위로 스크롤해 읽고 있으면 끌어내리지 않고,
   스크린 리더에는 다 받은 뒤 한 번만 알립니다. 예전 람다처럼 JSON 으로 오면 한 번에 보여 줍니다.
   결과를 닫았다 다시 열면 묻기 대화가 그대로 남고(받던 풀이는 멈추고 받은 부분만 남김), 새 점괘가 되면 진행 중이던 묻기는 취소되고 늦게 온 답은 버립니다.
   다 받은 답만 다음 질문의 대화 기록으로 보냅니다.
   공유하기, 다시 점치기(적어 둔 물음은 그대로 두고 던지기 화면으로 돌아감).
5. `占法` 안내: 상단 메뉴와 결과 화면에서 열 수 있습니다.

공유 링크: `/?hex=1` 또는 `/?hex=1&changed=2` 로 열면 인트로·물음 없이 바로 결과가 열립니다.
이때는 3D·물리 엔진을 불러오지 않고, [다시 점치기]를 누르면 그때 불러오며 주소의 `?hex=` 도 지웁니다.

창이 떠 있으면(결과·직접 고르기·점법 안내) 그 아래는 `inert` 로 잠그고 자동 초점·던지기·흔들기를 막습니다.

## 기술 스택

- **렌더링**: three.js 0.160. 필요할 때만 그립니다(흔드는 중·던지는 중·카메라 이동 때만, 탭이 숨으면 멈춤).
  카메라는 사용자가 돌리지 않는 고정 구도입니다. 세로 화면은 손 안 동전 지름이 화면 폭의 약 17%, 판 위 동전이 약 13.5% 가 되도록 시야를 정하고,
  손에서 판까지의 궤적이 한 화면에 들어오도록 앞쪽 비스듬한 위에서 봅니다. 가로 화면은 조금 더 내려다보고 던지기 자리를 오른쪽 아래에 둡니다.
  날아가는 동전은 카메라가 은근히(22%만) 따라갑니다.
  화질은 데스크톱 DPR 2·그림자 2048, 터치 기기와 저사양은 DPR 1.5·그림자 1024 에서 시작하고, 처음 60프레임의 중앙 프레임 시간이 25ms 를 넘으면
  DPR 1·그림자 512 로 한 단계 더 낮춥니다. WebGL 컨텍스트를 잃으면 멈췄다가 복구되면 다시 그립니다.
  동작 줄이기 설정이면 카메라 추적·진입 연출·진동을 끕니다.
- **물리**: [Rapier](https://rapier.rs) `@dimforge/rapier3d` 0.21. wasm 을 별도 파일(약 3.1MB, br 약 0.85MB)로 내보내 `vite-plugin-wasm` 으로 불러옵니다.
  (생성 코드가 top-level await 를 써서 빌드 대상은 es2022.) node 시뮬레이터는 같은 버전의 `@dimforge/rapier3d-compat`(개발 의존성)을 씁니다.
  - 동전: 반경 0.5·두께 0.12 의 라운드 실린더 충돌체, CCD, 밀도 기반 질량·관성
  - **크기와 시간**: 동전 반경 0.5 단위를 실제 엽전 약 12mm 로 보고(1 단위 = 24mm) 실제 중력 9.81m/s² = 408.75 단위/s² 를 씁니다.
    실제 속도 그대로면 손에서 판까지 0.25초 남짓이라 눈으로 따라가기 어렵고 초당 20회 넘는 뒤집힘이 끊겨 보이므로,
    모든 움직임을 일관되게 0.65배 느리게 보여 줍니다(중력 408.75 × 0.65² ≈ 172.7). 이때 비행은 약 0.4~0.55초, 뒤집힘은 초당 5~10회입니다.
  - **손(그릇)**: kinematic 몸체 + 컵 모양 복합 충돌체(바닥·뚜껑·14조각 벽, 두께 0.35 로 흔들 때 빠져나가지 않게). 흔들기는 매 물리 스텝마다
    `setNextKinematicTranslation/Rotation` 으로 손을 옮기고(진폭 제한), 던질 때는 충돌체를 끄고 동전마다 판 위 목표점과 비행 시간에 맞춘
    포물선 속도와 날아가는 방향에 수직인 가로축 뒤집힘을 줍니다. 손이 판 운두 바깥에 있으므로 동전은 판 안으로 들어온 뒤에만
    보이지 않는 벽·다른 동전과 부딪힙니다(충돌 그룹). 판 밖에 멈춘 동전이 있으면 판정하지 않고 다시 던집니다.
  - 점판: 평평한 바닥 + 비스듬한 턱(35°) + 보이지 않는 안전벽. 매끈한 회전체 삼각망(내부 모서리 보정)
  - 고정 시간 간격 1/240초, 솔버 8회, 접촉 강성 13Hz + 누산기 + 렌더 보간(60Hz·120Hz 모두 부드럽게)
  - **공정성**: 손에 거둘 때마다 세 동전의 자세를 균일 무작위 회전으로 정하고, 결과는 판 위에 멈춘 자세로만 읽습니다.
  - 결과는 **물리 자세로만**, 그리고 세 동전이 모두 착지·저속·평평할 때만 판정(앞면 법선의 y 부호). 오래 안 멈추면 감쇠를 서서히 올려 물리적으로 가라앉히고,
    모서리로 서거나 기대 멈추면 아주 작게 밀어 눕히며, 그래도 10초를 넘기면 그 효는 다시 던집니다. 시간 초과로 결과를 확정하지 않습니다.
  - 구름 마찰 근사(자기 축 회전만 감쇠), 겹쳐 누운 동전의 접촉 떨림 억제
- **소리**: 오디오 파일 없이 WebAudio 모달 합성. Rapier 접촉 세기 이벤트로 동전-판 충돌(엽전 부분음 + 칠기 '툭')·동전끼리 충돌을 구분해 울리고,
  구르기·눕기 직전 흔들림은 회전 속도에 비례한 잦은 미세 충격(오일러 원반처럼 빨라짐)으로, 흔들기는 짤랑임으로 냅니다.
  손 벽에 닿는 소리는 내지 않습니다(손 안에서는 동전끼리 짤랑임만). 상단 메뉴의 [동전 소리]로 끄고 켜며(localStorage 저장), 버튼을 누르기 전에는 오디오를 열지 않습니다.
  iOS 에서 전화·화면 잠금 등으로 오디오가 중단(`interrupted`)되면 다음 탭·키 입력 때 다시 켭니다.
- **빌드**: Vite 5 (three·rapier 별도 청크)
- **글꼴**: 한자 붓글씨 `莫大毛筆 Bakudai Bold`(쓰는 글자만 남긴 서브셋), 한글 `Hahmlet`(Google Fonts 300/400/600)
- **결과 묻기 백엔드**: `lambda/ask` (Anthropic Messages API 프록시, 기본 모델 `claude-sonnet-5`). 서버는 괘 번호·변효 자리만 믿고
  괘사·효사는 자기 데이터(`lambda/ask/data`, `npm run sync:lambda` 로 src 에서 복사)로 다시 만듭니다.
  응답 스트리밍을 쓰므로 Function URL 은 InvokeMode=RESPONSE_STREAM 이어야 합니다. 자세한 내용은 `lambda/README.md`

## 개발

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # dist/
```

`?debug` 를 붙이면 `window.__ichingStage.debugState()` 로 손·동전·카메라 상태를 읽을 수 있고, `?timescale=0.2` 처럼 주면 물리·카메라·인트로 타이밍이
같은 비율로 느려집니다(녹화 검증용, `.qa/record.cjs` 가 CSS 애니메이션도 같은 비율로 늦춰 실제 속도 영상과 0.1초 간격 콘택트시트를 만듭니다).

## 동전점법 규칙

1. 동전 3개를 동시에 던진다
2. 앞면(陽) = 3점, 뒷면(陰) = 2점
3. 합계: 6(老陰), 7(少陽), 8(少陰), 9(老陽)
4. 이를 6번 반복하여 아래(初爻)부터 위(上爻)까지 괘를 세운다
5. 변효(6 또는 9)가 있으면 지괘(변화할 괘)도 함께 본다
