# 周易占卦 · 주역 동전점

동전 세 닢을 여섯 번 던져 괘를 세우고, 본괘·지괘·점단으로 풀이를 읽는 웹앱입니다.
먹과 한지, 옻칠과 금박, 주인(朱印)을 바탕으로 한 화면에서 3D 동전이 실제 물리로 구르고 눕습니다.

## 흐름

1. **인트로**: 한지 위로 먹이 번지고, 여섯 효가 붓으로 그어지고, `周易` 제목과 인장이 찍힌 뒤 판 위로 둥글게 걷힙니다(약 4초).
   - 같은 세션에서 다시 열면 짧은 인트로(약 2초), 동작 줄이기 설정이면 정지 화면 뒤 짧은 페이드, 공유 링크로 들어오면 생략합니다.
   - 아무 곳이나 누르거나 `건너뛰기`, 키 입력으로 넘길 수 있습니다. 인트로가 시작되면 물리 엔진(wasm)과 3D 코드를 내려받기 시작하고,
     장면 구성은 인트로가 걷힌 뒤 한가할 때 합니다.
2. **물음**: "무엇을 묻고자 하십니까?" 에 200자까지 적거나 건너뜁니다. 물음은 던지는 동안 상단(`問`)과 결과 상단에 보이고,
   問占(LLM)에 맥락으로 전달됩니다. **공유 링크에는 담기지 않습니다.**
3. **마음 모으기**: 숨 고르기 원(들이쉬고/내쉬고)과 함께 "질문을 마음에 깊이 품고, 한 번 던질 때마다 그 생각에 머무르며 동전을 여섯 번 던지십시오" 안내.
   모션 센서가 있으면 흔들어 던지는 법도 함께 알려 주고, iOS 는 [마음을 모았습니다]를 누를 때 동작 권한을 묻는다고 미리 안내합니다.
4. **던지기**: 初爻부터 上爻까지 여섯 번. 왼쪽 효 사다리에 한 줄씩 쌓이고(老陽 ○, 老陰 × 표시), 매번 세 동전의 앞뒤와 효(少陽·老陰 등)를 알려 줍니다.
   - **폰 흔들어 털기**: 모션 센서가 있는 폰에서는 폰을 흔들어 기운을 모으고(버튼 윗선의 금색 게이지, 판 위 동전이 짤랑임) 털면 던져집니다.
     버튼도 언제나 쓸 수 있고, 흔들어 던진 효에는 "흔들어 던짐"이 작게 붙습니다. [흔들어 던지기 끄기]로 끌 수 있습니다(localStorage 저장).
     iOS 13+ 는 안내 단계의 [마음을 모았습니다]를 누를 때 동작 권한을 묻고, 거부·미지원이면 버튼 방식만 씁니다.
   - **다시 던지기**: 12초 안에 세 동전이 모두 착지·저속·평평 조건을 채우지 못하면 그 효는 기록하지 않고 동전을 거둬 다시 던지게 합니다(시뮬레이션에서 6,000회 중 1회).
   - **판 없이 던지기**: 던지기 화면에 들어오고 8초가 지나도 물리 엔진이 준비되지 않으면 [판 없이 던지기]가 나타나고, 물리 엔진을 불러오지 못하면 바로 이 방식으로 던집니다.
     이때는 `crypto.getRandomValues` 로 공정한 동전 세 닢을 정합니다. 물리 엔진이 나중에 준비되면 3D 던지기로 돌아갑니다.
   - **효 직접 고르기**: 손으로 동전을 던졌거나 이미 얻은 괘가 있으면, 안내 단계나 던지기 화면의 [효 직접 고르기]에서 初爻부터 上爻까지
     老陰(6)·少陽(7)·少陰(8)·老陽(9)을 고릅니다(각 값 옆에 동전 조합 힌트). 고르는 동안 괘 그림과 본괘·지괘 이름이 바로 보이고,
     여섯 줄을 다 채우면 [점괘 보기]가 켜집니다. 던지던 중에 열면 이미 던진 효가 채워져 있고, 진행 중이던 던지기는 취소됩니다.
     결과는 던진 괘와 같은 경로(점단·問占·공유)를 타며 "직접 입력한 괘" 표시가 붙습니다.
5. **결과(한지 두루마리)**: 本卦·之卦 그림과 이름, 괘사·대상, 占斷(변효 개수에 따른 판단 근거), 問占(점괘에게 묻기, 멀티턴).
   물음이 있으면 첫 칩이 "품은 질문에 대한 풀이 보기" 입니다. 묻기는 물음과 품은 질문을 AI 풀이 서버로 보낸다는 고지를 함께 보여 줍니다.
   결과를 닫았다 다시 열면 묻기 대화가 그대로 남고, 새 점괘가 되면 진행 중이던 묻기는 취소되고 늦게 온 답은 버립니다.
   공유하기, 다시 점치기(이전 물음을 채운 채 물음 단계로).
6. `占法` 안내: 상단 바와 결과 화면에서 열 수 있습니다.

공유 링크: `/?hex=1` 또는 `/?hex=1&changed=2` 로 열면 인트로·물음 없이 바로 결과가 열립니다.
이때는 3D·물리 엔진을 불러오지 않고, [다시 점치기]를 누르면 그때 불러오며 주소의 `?hex=` 도 지웁니다.

창이 떠 있으면(결과·직접 고르기·점법 안내) 그 아래는 `inert` 로 잠그고 자동 초점·던지기·흔들기를 막습니다.

## 기술 스택

- **렌더링**: three.js 0.160. 필요할 때만 그립니다(던지는 중·카메라 이동·시점 조작 때만, 탭이 숨으면 멈춤).
  화질은 데스크톱 DPR 2·그림자 2048, 터치 기기와 저사양은 DPR 1.5·그림자 1024 에서 시작하고, 처음 60프레임의 중앙 프레임 시간이 25ms 를 넘으면
  DPR 1·그림자 512 로 한 단계 더 낮춥니다. WebGL 컨텍스트를 잃으면 멈췄다가 복구되면 다시 그립니다. 창 크기가 바뀌어도 사용자가 돌려 놓은 시점은 유지합니다.
  동작 줄이기 설정이면 카메라 추적·진입 연출·진동을 끕니다.
- **물리**: [Rapier](https://rapier.rs) `@dimforge/rapier3d` 0.21. wasm 을 별도 파일(약 3.1MB, br 약 0.85MB)로 내보내 `vite-plugin-wasm` 으로 불러옵니다.
  (생성 코드가 top-level await 를 써서 빌드 대상은 es2022.) node 시뮬레이터는 같은 버전의 `@dimforge/rapier3d-compat`(개발 의존성)을 씁니다.
  - 동전: 반경 0.5·두께 0.12 의 라운드 실린더 충돌체, CCD, 밀도 기반 질량·관성
  - 점판: 평평한 바닥 + 비스듬한 턱(35°) + 보이지 않는 안전벽. 매끈한 회전체 삼각망(내부 모서리 보정)
  - 고정 시간 간격 1/120초 + 누산기 + 렌더 보간(60Hz·120Hz 모두 부드럽게)
  - 결과는 **물리 자세로만**, 그리고 세 동전이 모두 착지·저속·평평할 때만 판정(앞면 법선의 y 부호). 오래 안 멈추면 감쇠를 서서히 올려 물리적으로 가라앉히고,
    모서리로 서거나 기대 멈추면 아주 작게 밀어 눕히며, 그래도 12초를 넘기면 그 효는 다시 던집니다. 시간 초과로 결과를 확정하지 않습니다.
  - 구름 마찰 근사(자기 축 회전만 감쇠), 겹쳐 누운 동전의 접촉 떨림 억제
- **소리**: 오디오 파일 없이 WebAudio 모달 합성. Rapier 접촉 세기 이벤트로 동전-판 충돌(엽전 부분음 + 칠기 '툭')·동전끼리 충돌을 구분해 울리고,
  구르기·눕기 직전 흔들림은 회전 속도에 비례한 잦은 미세 충격(오일러 원반처럼 빨라짐)으로, 흔들기는 짤랑임으로 냅니다.
  상단 스피커 버튼으로 끄고 켜며(localStorage 저장), 버튼을 누르기 전에는 오디오를 열지 않습니다.
  iOS 에서 전화·화면 잠금 등으로 오디오가 중단(`interrupted`)되면 다음 탭·키 입력 때 다시 켭니다.
- **빌드**: Vite 5 (three·rapier 별도 청크)
- **글꼴**: 한자 붓글씨 `莫大毛筆 Bakudai Bold`(쓰는 글자만 남긴 서브셋), 한글 `Hahmlet`(Google Fonts 300/400/600)
- **결과 묻기 백엔드**: `lambda/ask` (Anthropic Messages API 프록시, 기본 모델 `claude-sonnet-5`). 서버는 괘 번호·변효 자리만 믿고
  괘사·효사는 자기 데이터(`lambda/ask/data`, `npm run sync:lambda` 로 src 에서 복사)로 다시 만듭니다. 자세한 내용은 `lambda/README.md`

## 개발

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # dist/
```

개발 모드에서는 `M` 키를 누르고 있으면 흔들기, 떼면 털기로 데스크톱에서 흔들어 던지기를 시험할 수 있습니다.

| 명령 | 하는 일 |

## 동전점법 규칙

1. 동전 3개를 동시에 던진다
2. 앞면(陽) = 3점, 뒷면(陰) = 2점
3. 합계: 6(老陰), 7(少陽), 8(少陰), 9(老陽)
4. 이를 6번 반복하여 아래(初爻)부터 위(上爻)까지 괘를 세운다
5. 변효(6 또는 9)가 있으면 지괘(변화할 괘)도 함께 본다
